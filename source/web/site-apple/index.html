    How it works

    Broadcasting in three steps.

    No servers, no accounts, no cloud. Just your Wi-Fi and two small apps.

    01

    Install both apps.

    FocusIn Teacher on your Mac. FocusIn Student on every iMac you want to reach.

    02

    Join the same Wi-Fi.

    Devices find each other automatically with Bonjour. No IPs, pairing, or network setup.

    03

    Press broadcast.

    Your screen appears on every selected Mac in real time. Lock, launch, or shut down from one window.

    About two minutes to set up. Grant Screen Recording to Teacher and Accessibility to Student on first launch. Then the room is ready.

    FAQ

    Good questions.

    Everything you need to know before the first bell.

    Ask on GitHub ↗

    Teacher needs Screen Recording to capture your display. Student needs Accessibility to intercept input during focus lock. On first shutdown or restart, macOS may also ask for Automation permission. All of these live in System Settings → Privacy & Security.

    No. FocusIn runs entirely on your local network. Teacher and Student discover each other with Bonjour and connect directly over WebSocket. The internet is only used when you check for updates.

    Any number of Macs running FocusIn Student on the same subnet. The practical limit is your Wi-Fi access point, not the app. Use a network that allows multicast and client-to-client traffic for the best experience.

    A local admin can press ⌘⇧U on the locked Mac and enter the admin password to unlock it. Set the password in the Student app first. The teacher can also unlock remotely as soon as the Mac is back online.

    Audio broadcasting is available on the Alpha build: 48 kHz stereo, sent on a dedicated channel with a jitter buffer. The stable build is video-only by design, which avoids the audio path entirely. Use the Alpha build to test audio and report issues.

    Yes. FocusIn is a universal macOS app and runs on macOS 14 or later. It is built with Swift, SwiftUI, Network.framework, and ScreenCaptureKit — no browser engine, no Electron.

    FocusIn is signed with a self-signed certificate, not a paid Apple Developer ID, so Gatekeeper may block the first launch. Right-click the app → Open → Open again. For lab deployment, install the FocusIn signing certificate from the repository's tools folder once per Mac.

    Absolutely. It is a general-purpose local screen broadcaster: workshops, demos, code reviews, events — anywhere one screen needs to be visible on many Macs at once.
