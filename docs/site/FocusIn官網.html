一體化管理

課堂需要的，一次到位。

從屏幕廣播到遠端控制，FocusIn 把教師最常用的操作收進一個乾淨的視窗。

屏幕廣播

ScreenCaptureKit 原生採集，30fps 高畫質傳輸，低延遲二進位幀管線；正式版內建畫面銳化，文字更清晰。

Kiosk 全屏鎖定

鎖定後全屏覆蓋、攔截鼠標鍵盤與 ⌘Tab／⌘⌥Esc／Ctrl+方向鍵，學生機只顯示教師廣播畫面。

遠端控制

關機、重新啟動、啟動指定 App（NSWorkspace）一鍵下發，可選全部學生或個別學生。

清空文件

遠端清空學生機 Documents 與 Downloads，教師需輸入 DELETE 二次確認，避免誤操作。

自動更新

啟動即檢查 GitHub Releases，穩定版／測試版各自分流，有新版本一鍵下載。

退出保護

統一管理員密碼：教師端退出、學生端退出、緊急解鎖（⌘⇧U）共用同一密碼，未設定無法退出。

即時廣播

教師屏幕，即時送達每一台學生機。

Bonjour 自動發現同網段學生端，勾選「全部學生」或個別目標即可開播。畫質提供自動／低／中／高三檔，高畫質為原生全分辨率 30fps。

  • 低延遲二進位幀管線，不經 base64／JSON
  • 正式版內建 CISharpenLuminance 畫面銳化
  • 學生端鎖定後全屏顯示廣播畫面

功能總覽

每一個細節，都是為了課堂。

教師端與學生端的分工，讓教學專注、讓學生專心。

Bonjour 自動發現

學生端啟動後透過 mDNS 廣播（_classroom-ctrl._tcp.），教師端自動列出在線裝置與延遲，無需手動配 IP。

屏幕廣播與銳化

ScreenCaptureKit 原生採集，自動／低／中／高畫質切換；正式版廣播前套用 CISharpenLuminance，文字邊緣更銳利。

Kiosk 全屏鎖定

鎖定後全屏覆蓋並攔截本機輸入：鼠標、鍵盤、⌘Tab、⌘⌥Esc、Ctrl+左右方向鍵；鎖窗自愈，接上新顯示器自動重建。

退出保護與管理員密碼

統一密碼同時保護教師端退出、學生端退出與緊急解鎖；教師端設定後即時下發所有已連線學生端，未設密碼無法退出。

遠端控制

遠端關機、重新啟動、啟動指定應用程式（依 Bundle ID，如 com.apple.Safari），可選全部或個別學生。

清空文件

遠端清空學生機 Documents 與 Downloads；教師必須輸入 DELETE 二次確認，杜絕誤觸。

自動更新

啟動即檢查 GitHub Releases，穩定／Alpha／Beta 各自分流，語義化版本比較，新版本一鍵下載。

登入自動啟動

教師端／學生端可設定登入 macOS 時自動啟動，開機即就緒，不需手動開啟。

權限指引

教師端需「屏幕錄製」、學生端需「輔助功能」；未授權時 app 內直接提示開啟路徑，附詳細系統設定步驟。

學生端 · 鎖定狀態
學生端

鎖定，就要鎖得徹底。

鎖定期間全屏覆蓋、攔截本機輸入，並隱藏選單列與 Dock；教師廣播畫面即時顯示在鎖窗上。網路異常時，管理員可在學生機本機輸入管理員密碼緊急解鎖。

  • 攔截 ⌘Tab、⌘⌥Esc、Ctrl+左右方向鍵
  • 鎖窗強制置頂，全屏 Space 也蓋得住
  • ⌘⇧U 緊急解鎖，需管理員密碼

遇到問題先看常見問答；找不到答案，直接私訊回報。

教師端廣播需要哪些權限？+

開啟「系統設定 → 私隱與安全性 → 屏幕錄製」，勾選 FocusIn 教師端。若先前選過「拒絕」，請先在該頁取消勾選再重新勾選。

學生端鎖定無效／攔截不到快捷鍵？+

開啟「系統設定 → 私隱與安全性 → 輔助功能」，勾選 FocusIn 學生端。鎖定攔截（鼠標、鍵盤、⌘Tab 等）與 ⌘⇧U 緊急解鎖都需要此權限。

學生機找不到教師端？+

確認教師機與學生機在同一 Wi-Fi／同一子網段，學生端已啟動，且防火牆未阻擋 Network.framework 通訊（mDNS 5353／WebSocket）。

緊急解鎖的密碼是什麼？+

與「管理員密碼」相同——教師端設定後會下發所有已連線學生端。學生機本機按 ⌘⇧U 輸入該密碼即可解鎖（即使斷網）。

如何更新到最新版？+

FocusIn 啟動時會自動檢查 GitHub Releases 並提示；也可手動在「檢查更新」按鈕觸發，或直接到 GitHub Releases 下載最新 DMG。

Alpha 版聲音有問題？+

Alpha 用於聲音廣播測試。若遇到延遲、雜音或卡頓，記錄版本號（v1.3.7-alpha）與設備型號，私訊回報 IG：marco.tsk_smile。
