每一個細節，都是為了課堂。

教師端與學生端的分工，讓教學專注、讓學生專心。

Bonjour 自動發現
學生端啟動後透過 mDNS 廣播（_classroom-ctrl._tcp.），教師端自動列出在線裝置與延遲，無需手動配 IP。
Kiosk 全屏鎖定
鎖定後全屏覆蓋並攔截本機輸入：鼠標、鍵盤、⌘Tab、⌘⌥Esc、Ctrl+左右方向鍵；鎖窗自愈，接上新顯示器自動重建。
退出保護
統一密碼同時保護教師端退出、學生端退出與緊急解鎖；教師端設定後即時下發所有已連線學生端，未設密碼無法退出。
正式版
清空文件
遠端清空學生機 Documents 與 Downloads；教師必須輸入 DELETE 二次確認，杜絕誤觸。
自動更新（直接下載）
啟動即檢查 GitHub Releases，發現新版本一鍵直接下載 DMG 到本機，下載完成即提示安裝。
登入自動啟動
教師端／學生端可設定登入 macOS 時自動啟動，開機即就緒，不需手動開啟。
權限指引
教師端需「屏幕錄製」、學生端需「輔助功能」；未授權時 app 內直接提示開啟路徑，附詳細系統設定步驟。
緊急解鎖 ⌘⇧U
網路異常時，管理員可在學生機本機按 ⌘⇧U，輸入與教師端相同的管理員密碼即可解鎖。

攔截系統快捷鍵
攔截 ⌘Tab（App 切換器）、⌘⌥Esc（強制結束）、Ctrl+左右方向鍵（Space／桌面切換），學生無法繞過鎖定。

我們可以幫到你。

遇到問題先看常見問答；找不到答案，直接私訊回報。

教師端廣播需要哪些權限？+

開啟「系統設定 → 私隱與安全性 → 屏幕錄製」，勾選 FocusIn 教師端。若先前選過「拒絕」，請先在該頁取消勾選再重新勾選。

學生端鎖定無效／攔截不到快捷鍵？+

開啟「系統設定 → 私隱與安全性 → 輔助功能」，勾選 FocusIn 學生端。鎖定攔截（鼠標、鍵盤、⌘Tab 等）與 ⌘⇧U 緊急解鎖都需要此權限。

學生機找不到教師端？+

確認教師機與學生機在同一 Wi-Fi／同一子網段，學生端已啟動，且防火牆未阻擋 Network.framework 通訊（mDNS 5353／WebSocket）。

緊急解鎖的密碼是什麼？+

與「管理員密碼」相同——教師端設定後會下發所有已連線學生端。學生機本機按 ⌘⇧U 輸入該密碼即可解鎖（即使斷網）。

如何更新到最新版？+

FocusIn 啟動時會自動檢查 GitHub Releases 並提示；點「下載更新」會直接下載 DMG，完成後自動提示安裝。也可手動觸發「檢查更新」。

Pro Key 在哪裡輸入？+

在教師端或學生端的「升級 Pro」區塊輸入 License Key 即可解鎖。Key 由官網「定價」頁購買產生；未購買時可先享受 7 天免費試用。
