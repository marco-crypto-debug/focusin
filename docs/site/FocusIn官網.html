How it works

Broadcasting in three steps.

No servers, no accounts, no cloud. Just your Wi-Fi and two apps.

1

Install both apps

Put FocusIn Teacher on your Mac, and FocusIn Student on every screen you want to reach.

2

Join the same Wi-Fi

Devices find each other automatically via Bonjour. Online students appear in the Teacher list with latency.

3

Press broadcast

Your screen streams to every selected device in real time. Adjust quality, lock, or send commands anytime.

Install with Homebrew macOS · Homebrew 
# 1. Add the FocusIn tap (once)
brew tap marco-crypto-debug/homebrew-focusin
# 2. Install Teacher and/or Student
brew install --cask focusin-teacher
brew install --cask focusin-student
# 3. Update later
brew upgrade --cask focusin-teacher focusin-student

On first launch, grant the permissions shown: Teacher needs Screen Recording, Student needs Accessibility. The apps are available in English, Traditional Chinese and Simplified Chinese.

Support

Questions you might have.

Check the FAQ first; if you can't find an answer, DM us.

What permissions does FocusIn need?+
Teacher: System Settings → Privacy & Security → Screen Recording, enable FocusIn. If you previously chose "Decline", uncheck and re-check. Student: System Settings → Privacy & Security → Accessibility, enable FocusIn for lock and input blocking.
Does Homebrew update work with auto-update?+
Yes. You can update either way: brew upgrade --cask focusin-teacher focusin-student, or press "Check for updates" in the app, which downloads the latest DMG directly.
Devices can't find each other?+
Make sure both apps are on the same Wi-Fi / subnet, the Student app is running, and the firewall allows Network.framework (mDNS 5353 / WebSocket).
What is the emergency unlock password?+
The same admin password set in the Teacher app — it is pushed to all connected students. Press ⌘⇧U on the student Mac and enter it, even offline.
Where do I enter my Pro Key?+
In the "Upgrade to Pro" section of the Teacher or Student app. Keys are generated on this site's Pricing page. No key yet? Enjoy the 7-day free trial.
Can I use FocusIn outside a classroom?+
Absolutely. It's a general-purpose screen broadcaster: demos, presentations, code reviews, events — anywhere you need one screen visible on many Macs at once.
